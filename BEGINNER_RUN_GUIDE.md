# Beginner Run Guide

I am not a full-stack engineer, so I designed this to be as easy to run as possible! 

You can run this project in two ways: The easy Docker way, or the manual split way.

## Option 1: The Easy Docker Way (Recommended)
If you have Docker installed on your PC:
1. Open your terminal in the root folder (`futurelabs-escape-silk-board-assessment`).
2. Make sure you added your `.env.local` inside `frontend/` as described in `API_SETUP_GUIDE.md`.
3. Run this command:
   ```bash
   docker-compose up --build
